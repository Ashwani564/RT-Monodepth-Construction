    **f) Compute Standard Metrics:**
    Implement the 7 standard metrics:
    - **Absolute Relative Error (AbsRel):** `mean(|gt - pred| / gt)`
    - **Squared Relative Error (SqRel):** `mean((gt - pred)^2 / gt)`
    - **Root Mean Squared Error (RMSE):** `sqrt(mean((gt - pred)^2))`
    - **RMSE log:** `sqrt(mean((log(gt) - log(pred))^2))`
    - **Accuracy thresholds (δ < 1.25):** `% of pixels where max(gt/pred, pred/gt) < 1.25`
    - **δ < 1.25²:** Same with threshold 1.5625
    - **δ < 1.25³:** Same with threshold 1.953125

5.  **Step 2b: Temporal Consistency Metrics**
    
    Implement these metrics:
    
    **a) Temporal Alignment Error (TAE) - Primary Metric:**
    ```python
    def compute_tae(pred_depths, gt_depths):
        """
        Measures if model's depth changes match ground truth changes
        """
        tae_scores = []
        for t in range(len(pred_depths) - 1):
            pred_t = pred_depths[t]
            pred_t1 = pred_depths[t + 1]
            gt_t = gt_depths[t]
            gt_t1 = gt_depths[t + 1]
            
            # Compute ratio of change (avoid division by zero)
            pred_ratio = pred_t / (pred_t1 + 1e-6)
            gt_ratio = gt_t / (gt_t1 + 1e-6)
            
            # MSE between ratios
            tae = np.mean((pred_ratio - gt_ratio) ** 2)
            tae_scores.append(tae)
        
        return np.mean(tae_scores)
    ```
    
    **b) Frame-to-Frame Depth Variance:**
    ```python
    def compute_depth_variance(pred_depths):
        """
        Measures how much depth changes between consecutive frames
        Lower = more stable (assuming static scene)
        """
        variances = []
        for t in range(len(pred_depths) - 1):
            diff = np.abs(pred_depths[t] - pred_depths[t + 1])
            variances.append(np.mean(diff))
        return np.mean(variances), np.std(variances)
    ```
    
    **c) Optical Flow-Weighted Consistency (Advanced):**
    ```python
    # If available, use optical flow to account for camera motion
    # Areas with low optical flow should have low depth change
    def compute_flow_weighted_consistency(pred_depths, optical_flows):
        """
        Penalize depth changes in static regions
        """
        consistency_scores = []
        for t in range(len(pred_depths) - 1):
            depth_diff = np.abs(pred_depths[t] - pred_depths[t + 1])
            flow_magnitude = np.linalg.norm(optical_flows[t], axis=-1)
            
            # Static regions (low flow) should have low depth change
            static_mask = flow_magnitude < 2.0  # threshold
            static_depth_change = depth_diff[static_mask]
            
            consistency_scores.append(np.mean(static_depth_change))
        
        return np.mean(consistency_scores)
    ```

### **Stage 3: Performance (FPS)**

**Goal:** Prove your RT-MonoDepth model meets its "RT" (Real-Time) claim across different platforms.

**Your Action Plan:**

2.  **Adapt from Your Multi-Platform Code:**
    Your project supports MacBook M1 Pro, Linux, and Jetson Nano. The FPS benchmark should test on all target platforms.
    
    From `realtime_depth_video.py`, you already handle:
    - MLX acceleration for Apple Silicon
    - CUDA for Linux/Jetson
    - CPU fallback
    
3.  **Script Structure:**
    ```python
    import torch
    import time
    import platform
    import argparse
    from networks.RTMonoDepth.RTMonoDepth import DepthDecoder, DepthEncoder
    from networks.RTMonoDepth.RTMonoDepth_s import DepthDecoder as DepthDecoderS, DepthEncoder as DepthEncoderS
    from layers import disp_to_depth
    
    def benchmark_model(model_path, resolution=(640, 192), num_warmup=30, num_iterations=100):
        # Detect platform and device
        if torch.cuda.is_available():
            device = torch.device("cuda")
            platform_name = "CUDA"
        elif torch.backends.mps.is_available():
            device = torch.device("mps")
            platform_name = "MPS (Apple Silicon)"
        else:
            device = torch.device("cpu")
            platform_name = "CPU"
        
        # Load model (same as Stage 1)
        is_small_model = "/s/" in model_path
        if is_small_model:
            encoder = DepthEncoderS()
            decoder = DepthDecoderS(encoder.num_ch_enc)
        else:
            encoder = DepthEncoder()
            decoder = DepthDecoder(encoder.num_ch_enc)
        
        encoder_path = os.path.join(model_path, "encoder.pth")
        depth_path = os.path.join(model_path, "depth.pth")
        encoder.load_state_dict(torch.load(encoder_path, map_location=device))
        decoder.load_state_dict(torch.load(depth_path, map_location=device))
        
        encoder.to(device).eval()
        decoder.to(device).eval()
        
        # Create dummy input (batch_size=1)
        width, height = resolution
        dummy_input = torch.randn(1, 3, height, width).to(device)
        
        # Warm-up phase (CRITICAL!)
        print(f"Warming up ({num_warmup} iterations)...")
        for _ in range(num_warmup):
            with torch.no_grad():
                features = encoder(dummy_input)
                outputs = decoder(features)
        
        # Synchronize device
        if device.type == "cuda":
            torch.cuda.synchronize()
        elif device.type == "mps":
            torch.mps.synchronize()
        
        # Benchmark phase
        print(f"Running benchmark ({num_iterations} iterations)...")
        t_start = time.perf_counter()
        
        for _ in range(num_iterations):
            with torch.no_grad():
                features = encoder(dummy_input)
                outputs = decoder(features)
        
        # Synchronize again
        if device.type == "cuda":
            torch.cuda.synchronize()
        elif device.type == "mps":
            torch.mps.synchronize()
        
        t_end = time.perf_counter()
        
        # Calculate metrics
        total_time = t_end - t_start
        avg_time = total_time / num_iterations
        fps = 1.0 / avg_time
        
        return {
            'platform': platform_name,
            'device': str(device),
            'resolution': resolution,
            'avg_time_ms': avg_time * 1000,
            'fps': fps,
            'total_iterations': num_iterations
        }
    ```
