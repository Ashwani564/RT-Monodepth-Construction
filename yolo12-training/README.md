# YOLOv12n Training - Construction Safety Dataset

Complete training pipeline for YOLOv12n on merged construction safety dataset.

## Dataset Structure

**18 Classes Total:**
- **Classes 0-16:** Construction Equipment (Dump truck, Excavator, Motor grader, etc.)
- **Class 17:** Person

## Quick Start

### 1. Convert Person Dataset (CSV → YOLO format)

```bash
cd yolo12-training
python convert_person_csv_to_yolo.py
```

This converts the person dataset annotations from CSV format to YOLO format with class ID 17.

### 2. Merge Datasets

```bash
python merge_datasets.py
```

This merges:
- Person dataset (class 17)
- Construction equipment dataset (classes 0-16)

Into a single unified dataset at `merged_construction_safety/`

### 3. Train YOLOv12n

```bash
python train_yolo12n.py
```

Trains YOLOv12n model on the merged dataset.

## Training Parameters

- **Model:** YOLOv12n (nano - fastest variant)
- **Epochs:** 100
- **Batch Size:** 16 (adjust based on GPU memory)
- **Image Size:** 640×640
- **Device:** Auto-detect (CUDA > MPS > CPU)
- **Optimizer:** Auto (AdamW recommended)
- **Learning Rate:** 0.01 → 0.0001 (cosine schedule)

## Troubleshooting

### Out of Memory Error

Reduce batch size in `train_yolo12n.py`:
```python
'batch': 8,  # Instead of 16
```

Or reduce image size:
```python
'imgsz': 416,  # Instead of 640
```

### Slow Training

Enable image caching (requires ~100GB RAM):
```python
'cache': True,
```

### Resume Training

If training interrupted:
```python
'resume': True,
```

Or manually:
```bash
yolo train resume model=runs/yolo12n_construction_safety/weights/last.pt
```

## After Training

### Evaluate Model

```bash
yolo val model=runs/yolo12n_construction_safety/weights/best.pt data=data.yaml
```

### Export to ONNX

```bash
yolo export model=runs/yolo12n_construction_safety/weights/best.pt format=onnx
```

### Run Inference

```bash
yolo predict model=runs/yolo12n_construction_safety/weights/best.pt source=image.jpg
```
