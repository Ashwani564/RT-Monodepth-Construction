# Dataset Download Guide for Stage 1 Evaluation
# RT-MonoDepth-Construction Benchmark - Multi-Dataset Evaluation

## 📥 Required Datasets for Stage 1

As per REVISED_BENCHMARK_PLAN.md, Stage 1 evaluates RT-MonoDepth across multiple datasets to demonstrate:
- ✅ Relative depth ordering accuracy (scale-invariant metrics)
- ✅ Generalization across indoor/outdoor scenes
- ✅ Comparison with SOTA monocular depth methods

---

### 1. NYU Depth V2 (Indoor Baseline) - **REQUIRED**

**Purpose:** Standard academic benchmark for indoor depth estimation
**Test Split:** 654 Eigen test split images

**Download Link:**
```
http://horatio.cs.nyu.edu/mit/silberman/nyu_depth_v2/nyu_depth_v2_labeled.mat
```

**Direct Download:**
```bash
mkdir -p datasets/nyu_depth_v2
cd datasets/nyu_depth_v2
curl -O http://horatio.cs.nyu.edu/mit/silberman/nyu_depth_v2/nyu_depth_v2_labeled.mat
cd ../..
```

**Alternative (if direct fails):**
- Visit: http://horatio.cs.nyu.edu/mit/silberman/nyu_depth_v2/
- Download: `nyu_depth_v2_labeled.mat` (2.8 GB)

**Place at:** `datasets/nyu_depth_v2/nyu_depth_v2_labeled.mat`

**Size:** ~2.8 GB

---

### 2. KITTI Depth Dataset (Outdoor - Construction Site Proxy) - **REQUIRED**

**Website:** http://www.cvlibs.net/datasets/kitti/eval_depth.php?benchmark=depth_prediction

**What to Download:**

**Option A: Eigen Split (Recommended for academic comparison)**

1. **Download annotated depth maps** (~14 GB):
   ```
   http://www.cvlibs.net/download.php?file=data_depth_annotated.zip
   ```
   - Unzip to: `datasets/kitti/`

2. **Download raw data** (Select sequences from Eigen split):
   ```
   http://www.cvlibs.net/download.php?file=raw_data_downloader.zip
   ```
   - Or download specific sequences:
     - 2011_09_26_drive_0001 (residential)
     - 2011_09_26_drive_0002 (residential)
     - 2011_09_26_drive_0005 (residential)
     - 2011_09_26_drive_0009 (residential)
     - ... (see eigen_split.txt for full list)

**Option B: Quick Start (Smaller Download)**

Download only the Eigen test split:
- Ground truth depths: http://www.cvlibs.net/datasets/kitti/eval_depth.php?benchmark=depth_prediction
- Click "Download annotated depth maps (14GB)"

**Place at:** 
```
datasets/kitti/
├── 2011_09_26/
├── 2011_09_28/
├── 2011_09_29/
├── 2011_09_30/
├── 2011_10_03/
└── gt_depths/
```

### 3. Cityscapes Dataset (Urban Pedestrian Scenes) - **RECOMMENDED**

**Purpose:** Outdoor pedestrian scenarios, tests generalization to outdoor human detection
**Better domain match for construction sites than indoor NYU**

**Website:** https://www.cityscapes-dataset.com/

**What to Download:**

1. **Register** (free academic account required)
   - Visit: https://www.cityscapes-dataset.com/register/
   - Fill in academic information

2. **Download leftImg8bit_sequence_trainvaltest.zip** (324 GB - full sequences)
   - OR **Download leftImg8bit_trainvaltest.zip** (11 GB - single frames only)
   - Contains validation set with outdoor scenes

3. **Download camera_trainvaltest.zip** (2 MB)
   - Camera calibration files

4. **Optional: Disparity maps** (for depth ground truth)
   - Download: disparity_trainvaltest.zip (3.5 GB)

**Place at:**
```
datasets/cityscapes/
├── leftImg8bit/
│   ├── train/
│   ├── val/
│   └── test/
├── camera/
└── disparity/  (if downloaded)
```

**Size:** 11 GB (single frames) OR 324 GB (sequences)

**Note:** Cityscapes provides disparity maps. Convert to depth using:
```python
depth = (baseline * focal_length) / disparity
# Camera parameters available in camera/ folder
```

### 4. Make3D Dataset (Diverse Outdoor Scenes) - **OPTIONAL**

**Purpose:** Additional outdoor validation, diverse scene types

```
datasets/make3d/
```

**Size:** ~2 GB

## 🚀 Quick Download Script

Run this script to download datasets automatically:

```bash
#!/bin/bash
# download_datasets.sh - Stage 1 Multi-Dataset Download

echo "📥 Downloading datasets for RT-MonoDepth Stage 1 Evaluation..."
echo "=================================================="

# Create directories
mkdir -p datasets/nyu_depth_v2
mkdir -p datasets/kitti
mkdir -p datasets/cityscapes
mkdir -p datasets/make3d
mkdir -p datasets/splits/eigen
mkdir -p datasets/splits/eigen_benchmark

# Download NYU Depth V2 (REQUIRED)
echo ""
echo "1️⃣  NYU Depth V2 (REQUIRED - Indoor baseline)"
echo "   Downloading (2.8 GB)..."
cd datasets/nyu_depth_v2
if [ ! -f "nyu_depth_v2_labeled.mat" ]; then
    curl -L -O http://horatio.cs.nyu.edu/mit/silberman/nyu_depth_v2/nyu_depth_v2_labeled.mat
    echo "   ✅ NYU Depth V2 downloaded"
else
    echo "   ✅ NYU Depth V2 already exists"
fi
cd ../..

# KITTI (REQUIRED - user must download manually)
echo ""
echo "2️⃣  KITTI Dataset (REQUIRED - Outdoor/driving)"
echo "   ⚠️  Must be downloaded manually (registration required):"
echo "   1. Visit: http://www.cvlibs.net/datasets/kitti/eval_depth.php?benchmark=depth_prediction"
echo "   2. Register/Login (free academic account)"
echo "   3. Download 'annotated depth maps' (14GB)"
echo "   4. Unzip to: datasets/kitti/"
echo ""

# Cityscapes (RECOMMENDED - user must download manually)
echo ""
echo "3️⃣  Cityscapes Dataset (RECOMMENDED - Urban pedestrians)"
echo "   ⚠️  Must be downloaded manually (registration required):"
echo "   1. Visit: https://www.cityscapes-dataset.com/downloads/"
echo "   2. Register (free academic account)"
echo "   3. Download 'leftImg8bit_trainvaltest.zip' (11GB)"
echo "   4. Download 'camera_trainvaltest.zip' (2MB)"
echo "   5. Optional: Download 'disparity_trainvaltest.zip' (3.5GB)"
echo "   6. Unzip to: datasets/cityscapes/"
echo ""

# Make3D (OPTIONAL)
echo ""
echo "4️⃣  Make3D Dataset (OPTIONAL - Diverse outdoor)"
echo "   Attempting to download Test134 set (2GB)..."
cd datasets/make3d
if [ ! -f "Test134.tar.gz" ]; then
    # Note: Make3D download link may require manual download
    echo "   ⚠️  Automatic download may fail. Manual download:"
    echo "   Visit: http://make3d.cs.cornell.edu/data.html"
    echo "   Download: Test134.tar.gz"
    echo "   Place in: datasets/make3d/"
else
    echo "   ✅ Make3D Test134 already exists"
    tar -xzf Test134.tar.gz 2>/dev/null || echo "   Extracting..."
fi
cd ../..

# Download Eigen split files
echo ""
echo "5️⃣  Downloading Eigen split files..."
mkdir -p datasets/splits/eigen
mkdir -p datasets/splits/eigen_benchmark

curl -o datasets/splits/eigen/test_files.txt \
    https://raw.githubusercontent.com/mrharicot/monodepth/master/utils/filenames/eigen_test_files.txt 2>/dev/null
echo "   ✅ NYU Eigen split downloaded (654 images)"

curl -o datasets/splits/eigen_benchmark/test_files.txt \
    https://raw.githubusercontent.com/mrharicot/monodepth/master/utils/filenames/eigen_benchmark_test_files.txt 2>/dev/null
echo "   ✅ KITTI Eigen split downloaded (697 images)"

echo ""
echo "=================================================="
echo "✅ Automated downloads complete!"
echo ""
echo "📋 Next Manual Steps:"
echo "   1. Download KITTI (see instructions above) - REQUIRED"
echo "   2. Download Cityscapes (see instructions above) - RECOMMENDED"
echo "   3. Verify all datasets with: bash verify_datasets.sh"
echo "   4. Run Stage 1 evaluation: python evaluate_depth_multi_dataset.py"
echo ""
echo "💡 Minimum for testing: NYU only (~3 GB)"
echo "💡 Full evaluation: NYU + KITTI (~17 GB)"
echo "💡 Complete benchmark: NYU + KITTI + Cityscapes + Make3D (~32 GB)"
```

Save as `download_datasets.sh` and run:
```bash
chmod +x download_datasets.sh
./download_datasets.sh
```

## 📊 Dataset Verification

After downloading, verify your setup with this script:

```bash
#!/bin/bash
# verify_datasets.sh - Verify Stage 1 datasets

echo "🔍 Verifying RT-MonoDepth Stage 1 Datasets..."
echo "=============================================="

# Check NYU Depth V2
echo ""
echo "1️⃣  NYU Depth V2:"
if [ -f "datasets/nyu_depth_v2/nyu_depth_v2_labeled.mat" ]; then
    SIZE=$(du -h datasets/nyu_depth_v2/nyu_depth_v2_labeled.mat | cut -f1)
    echo "   ✅ Found (Size: $SIZE)"
else
    echo "   ❌ NOT FOUND - Download required"
fi

# Check KITTI
echo ""
echo "2️⃣  KITTI Dataset:"
if [ -d "datasets/kitti" ] && [ "$(ls -A datasets/kitti)" ]; then
    echo "   ✅ Found"
    echo "   Contents: $(ls datasets/kitti | head -3 | tr '\n' ' ')..."
else
    echo "   ❌ NOT FOUND - Manual download required"
fi

# Check Cityscapes
echo ""
echo "3️⃣  Cityscapes Dataset:"
if [ -d "datasets/cityscapes/leftImg8bit" ]; then
    echo "   ✅ Found"
else
    echo "   ⚠️  NOT FOUND - Optional but recommended"
fi

# Check Make3D
echo ""
echo "4️⃣  Make3D Dataset:"
if [ -d "datasets/make3d/Test134" ]; then
    echo "   ✅ Found"
else
    echo "   ⚠️  NOT FOUND - Optional"
fi

# Check Eigen splits
echo ""
echo "5️⃣  Eigen Split Files:"
if [ -f "datasets/splits/eigen/test_files.txt" ]; then
    NYU_COUNT=$(cat datasets/splits/eigen/test_files.txt | wc -l | tr -d ' ')
    echo "   ✅ NYU split found ($NYU_COUNT images, expected 654)"
else
    echo "   ❌ NYU split NOT FOUND"
fi

if [ -f "datasets/splits/eigen_benchmark/test_files.txt" ]; then
    KITTI_COUNT=$(cat datasets/splits/eigen_benchmark/test_files.txt | wc -l | tr -d ' ')
    echo "   ✅ KITTI split found ($KITTI_COUNT images, expected 697)"
else
    echo "   ❌ KITTI split NOT FOUND"
fi

echo ""
echo "=============================================="
echo "📊 Storage Usage:"
du -sh datasets/nyu_depth_v2 2>/dev/null
du -sh datasets/kitti 2>/dev/null
du -sh datasets/cityscapes 2>/dev/null
du -sh datasets/make3d 2>/dev/null
echo ""
echo "✅ Verification complete!"
```

Save as `verify_datasets.sh` and run:
```bash
chmod +x verify_datasets.sh
./verify_datasets.sh
```

## 🆘 Troubleshooting

**Problem:** NYU download fails
- **Solution:** Use mirror or direct browser download from http://horatio.cs.nyu.edu/mit/silberman/nyu_depth_v2/

**Problem:** KITTI website requires registration
- **Solution:** Register (free) at http://www.cvlibs.net/datasets/kitti/user_login.php

**Problem:** Files corrupted after download
- **Solution:** Verify checksums or re-download

```bash
python evaluate_depth_multi_dataset.py \
```

